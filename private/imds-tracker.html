        Direct Microsoft cloud connection Optional · IT setup

        Reads the workbook straight from OneDrive/SharePoint through Microsoft Graph.

        Microsoft connection is not configured, so it is not offered. The tracker never fakes a cloud connection.

        How to enable it (IT admins)
        Register an Azure AD app with the read-only Files.Read.All delegated permission, then fill in MS_CONFIG at the top of the connection section in this file:
        const MS_CONFIG={
  clientId:"YOUR_AZURE_APP_CLIENT_ID",
  tenantId:"YOUR_AZURE_TENANT_ID",
  redirectUri:window.location.href.split("#")[0]
};
